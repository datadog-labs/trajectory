# Security Policy

## Reporting a Vulnerability

Report vulnerabilities through Datadog's coordinated disclosure process at
https://www.datadoghq.com/security/. Never report them in a public GitHub
issue.

Include the steps to reproduce the issue, the Trajectory version, the
operating system, and the coding agent. Say which part is affected: local
capture, plugin installation, credential handling, or Datadog export.

## Sensitive Data

To keep a session's content out of Datadog, see the
[privacy guide](docs/PRIVACY.md).
