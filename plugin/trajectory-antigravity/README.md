# Trajectory Antigravity Plugin

Capture plugin for Antigravity CLI (`agy`). Registers Gemini-compatible command hooks that post session events to the local Trajectory capture server and includes the Trajectory incognito skill.

Install through setup:

```bash
trajectory setup --clients agy
```

For manual validation with Antigravity CLI:

```bash
agy plugin validate plugin/trajectory-antigravity
```
